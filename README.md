\# Weather App



A simple Python Weather App that fetches real-time weather information using the Open-Meteo API.



\## Features



\- Enter a city name

\- Find city location using Geocoding API

\- Fetch current weather data

\- Display temperature in Celsius

\- Display temperature in Fahrenheit

\- Display humidity

\- Display weather code

\- Display wind speed

\- Handle invalid city names

\- Handle empty input

\- Handle network errors and request timeout



\## Technologies Used



\- Python

\- Requests

\- Open-Meteo API

\- JSON
